# Утилита фильтрации содержимого файлов

## Стек технологий

- **Java**: 17
- **Gradle**: 9.0.0 (с плагином [Shadow](https://github.com/GradleUp/shadow?tab=readme-ov-file) для генерации Fat Jar)

## Сторонние библиотеки

- **[JCommander](https://jcommander.org/)** 1.82

Библиотека используется для обработки аргументов командной строки.
```kotlin
dependencies {
    implementation("com.beust:jcommander:1.82")
}
```

## Сборка проекта

1. Склонируйте репозиторий:
```shell
git clone https://github.com/bobridze5/FileFilterUtil.git
```

2. перейдите в корневую директорию проекта:
```shell
cd FileFilterUtil
```

3. Для сборки исполняемого JAR-файла со всеми зависимостями выполните команду в корне проекта:
```shell
./gradlew build
```

## Запуск утилиты

### Формат команды:
```shell
java -jar build/libs/util.jar [Параметры] <файл_1.txt>, <файл_2.txt> ...
```
### Доступные параметры
- `-o`/`--output` `<путь>`: задать путь для результатов (по умолчанию использует текущую директорию);
- `-p`/`--prefix` `<название>`: задать префикс для имён выходных файлов (по умолчанию создаёт файлы без префикса: *integers.txt*, *floats.txt*, *strings.txt*);
- `-a`/`--append`: задать режим добавления в конец файлов (по умолчанию происходит перезапись файлов);
- `-s`/`--short`: вывод краткой статистики по каждому типу данных (количество элементов);
- `-f`/`--full`: вывод полной статистики по каждому типу данных (помимо количества минимальное, максимальное числа, сумма, среднее для чисел, и для строк минимальную и максимальную длины);
- `-h`/`--help`: вывод справки по параметрам.

## Пример работы

### Пример входного файла in1.txt
```text
Lorem ipsum dolor sit amet
45
Пример
3.1415
consectetur adipiscing
-0.001
тестовое задание
100500
```

### Пример входного файла in2.txt
```text
Нормальная форма числа с плавающей запятой
1.528535047E-25
Long
1234567890123456789
```

### Пример запуска утилиты
```shell
java -jar util.jar -s -a -p sample- in1.txt in2.txt
```
